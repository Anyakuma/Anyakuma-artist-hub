ANYAKUMA ARTIST HUB — FRONT-END STARTER

FILES
- index.html: page structure
- style.css: responsive visual styling
- script.js: catalogue, fan sign-up demo, community wall demo, and booking email draft

HOW TO RUN
1. Keep all three code files in the same folder.
2. Open index.html in a modern web browser.
3. Edit script.js to add real music catalogue details and links.
4. Replace CONFIG.bookingEmail with Anyakuma's actual booking email.

IMPORTANT LIMITATIONS
- Fan sign-ups and community posts are stored only in the current browser/device.
- The booking form opens a prefilled email draft; it does not submit to a server.
- A production launch needs a backend/database, secure fan management, spam protection,
  moderation, privacy notice, and server-side enquiry handling.
- Google Fonts requires an internet connection; fallback fonts are available.

This is a starter prototype, not a deployed or production-secured platform.
